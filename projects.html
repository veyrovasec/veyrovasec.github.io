Python Security Log Analyzer

A Python project that analyzes authentication logs, summarizes login activity, and identifies repeated failed login attempts.

What it currently does

  • Processes authentication log entries.
  • Distinguishes valid records from malformed entries.
  • Summarizes successful, failed, and denied login attempts.
  • Identifies repeated failures using a configurable threshold.
  • Validates input types and rejects invalid values.

Engineering practices

The project uses automated Python unit tests to check expected behavior, invalid inputs, exception handling, and whether functions preserve their input data.

Most recent recorded verification: 18 test methods passed, and full log analysis passed (Month 3, Day 2).

Status: Active learning project — under development.
